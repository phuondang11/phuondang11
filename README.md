## How I work

- **Understand the workflow:** clarify requirements, map user flows and identify edge cases, dependencies and technical constraints before implementation.
- **Stay hands-on:** implement frontend features and backend logic, integrate APIs, debug issues and review changes against business rules.
- **Lead by project:** split work by module and available capacity, assign clear ownership, coordinate dependencies and support teammates through review and feedback.
- **Deliver deliberately:** align scope and milestones, track blockers early, coordinate QA and releases, and keep stakeholders informed about delivery risks.
- **Use AI with verification:** use Claude and Codex for source analysis, task planning, implementation, debugging and review; verify suggestions against the codebase and run relevant checks before accepting changes.
